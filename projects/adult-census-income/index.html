Overview

Research Objective

Develop and compare machine learning classification models to predict whether an individual's annual income exceeds $50K using the Adult Census Income dataset, while evaluating the impact of optimization techniques on model performance.

Methodology

Applied data preprocessing including missing value imputation, categorical encoding, normalization, and SMOTE for class imbalance. Model performance was optimized using Genetic Algorithm (GA) and Particle Swarm Optimization (PSO), then evaluated through 10-fold cross-validation.

Analysis

Data Preprocessing

Income Distribution

The dataset shows an imbalance between income classes, where individuals with income below or equal to $50K dominate the dataset. Therefore, SMOTE was applied during preprocessing to improve model learning on minority classes.

Missing Values

Missing values initially represented by the "?" symbol were converted to NaN for proper identification. Numerical features were imputed using the mean value, while categorical features were filled with the most frequent value (mode).

Feature Encoding

Completed

Categorical variables were transformed into numerical values using Label Encoding before model training.

Conclusion

Main Findings

  • • Optimization techniques improved the overall classification performance compared to the baseline models.
  • • K-Nearest Neighbors consistently outperformed Naive Bayes across the evaluated performance metrics.
  • • Genetic Algorithm achieved the strongest performance improvement among the evaluated optimization techniques.

Practical Insight

The experimental results demonstrate that combining machine learning algorithms with optimization techniques can improve classification performance for income prediction. These findings highlight the potential of optimization methods to enhance predictive models for real-world decision support applications.
